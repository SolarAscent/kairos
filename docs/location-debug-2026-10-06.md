# 定位与路程核对调试（2026-10-06）

## 本轮修复

- 核对路程提交当前心愿的 `focusObjectId`，后端校验归属、有效状态和排除条件；后续澄清仍保持同一心愿，不会重新排序成另一件事。
- 地图查询名额独立从需要出行的候选中选择，室内阅读等推荐不再挤占五个地点的查询名额。具体完整地址不再被缺少独立城市字段阻断，地址解析仍须通过地图 Provider 的具体性校验。
- 往返路线查询的总期限从 2 秒调整为 4 秒，兼容腾讯步行路径每秒 4 次的请求节流；保留最多五个目标、两个并发任务、取消及失败降级。
- API 返回结构化 `routeCheck` 状态和原因，区分已核实、超时、额度、限流、地点不明确、正在忙等情况。路线成功仍须满足时间窗口等条件才能推荐出发。
- 核对按钮立即显示定位与往返核对进度，反馈位于建议卡片内部。定位回调最长等待 20 秒，超时后恢复按钮，忽略迟到结果；生活“附近”筛选共享定位诊断，并避免页面离开后写入过期位置。
