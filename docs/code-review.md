## 已修改

- **冗余与写法**：删除未使用的偏好请求定义、依赖和反馈服务数据库注入；合并重复分支，移除重复对象映射、伪造 request_id、自制 UUID 兼容代码及未使用的 Refresh Token 存储。开启未使用变量/参数检查，统一 Prettier 格式。
- **模型契约**：用 Zod 生成结构化输出 Schema，替代第二份手写定义；文本 Facet 使用明确字段，禁止模型声明 VERIFIED。关系索引越界直接校验失败，不再悄悄丢弃。Provider 拼写错误会启动失败，真实模型失败不会回退 Mock。依据 [OpenAI 结构化输出文档](https://developers.openai.com/api/docs/guides/structured-outputs)。
- **认证与反馈**：校验 JWT 头和负载、TTL、账号状态及会话有效期；并发首次登录串行创建身份。刷新轮换在事务内完成。反馈去重比较会话、事件、原因和 metadata，同一 client_event_id 并发请求只写一次。
- **后台任务**：共用事务和租约检查，以 owner + attempt 隔离过期 Worker；解析前可见 PROCESSING，解析后重新锁定 Capture，防止删除后复活或重复建对象。失败保留原文、记录模型失败并退避重试；未知事件不再标记 DONE。反馈信号使用原事件时间，记录 Worker 审计和 trace_id。
- **推荐与网页**：未知时长不冒充硬约束，文案遵守可用时间，过期边界正确，排序有稳定的平局规则；移除无依据的固定 actionability_score。防止重复提交/反馈，“换一个”累计排除本轮已跳过对象，移除尚未实现的画像学习效果承诺。
- **工程配置**：修正健康检查失败仍返回 200、迁移只识别首个文件、Compose 未迁移即启动、运行镜像没有 pnpm、Demo preview 工作目录错误等问题。Schema 的枚举、默认值、索引和约束与 SQL 基线对齐。核心写接口的 OpenAPI 请求/响应来自 Zod。

用户范围查询、数据库事务、租约隔离和外部输出校验是说明明确要求的业务保障，保留。

## 验证

本地构建与 TypeScript 严格检查通过。30 项自动测试通过：14 项单元测试、16 项真实 PostgreSQL 集成测试。覆盖文本完整闭环、并发登录和刷新、用户隔离、幂等冲突、反馈去重、模型失败重试、删除/租约竞态和 OpenAPI。测试创建独立 schema 并清理，没有修改现有业务数据库。

浏览器实际验证了登录、文本回执、后台转为“已理解”、生成单一行动和接受反馈。真实微信、OpenAI、腾讯云调用未执行。本机未安装 Docker，容器构建由新增 GitHub Actions 检查，不把本地静态检查当作容器运行通过。

## 与完整产品说明的剩余差距

- 仍是本地网页 + 文本后端；原生小程序、图片/语音、COS、腾讯 LBS/ASR、真实凭证联调、必要追问尚未交付。
- 当前 service 承担用例和数据库访问，未抽离 application/repository 包；没有为了目录数量创建空壳模块。预留的数据库表保留，避免破坏已有迁移。
- 列表目前有数量上限，尚无游标分页；Life 详情和决策读取响应尚未全部生成 Zod/OpenAPI 契约。认证接口尚未接入通用幂等响应存储；Refresh Token 单次轮换不等于网络重试可重放。
- 偏好信号已持久化，但画像重建、衰减和接入推荐尚未实现；投影仅包含当前文本 Demo 字段。没有将未知时间、金额、地点变成已验证事实。
- 删除/导出、保留期清理、生产 RLS、限流、完整遥测及客户端版本管理仍待实现。此次没有将 Demo 宣称为生产就绪。
