# Stitch 最终 20 页到原生小程序的实现映射

日期：2026-10-07

本文逐页对照 `stitch_remix_of (1).zip` 的 13 个 HTML 与 `stitch_remix_of (2).zip` 的 7 个 HTML，并记录当前原生小程序代码能承接的部分。两份 ZIP 的 `zipfile.testzip()` 均返回 `None`，可读取 20 个页面 HTML。设计稿中的地点、票券、营业时间、路线和日期均为示例文本，不作为用户事实或验收数据。

## 当前原生实现范围

小程序当前注册 `home`、`life-list`、`life-detail`、`settings`、`onboarding` 五个页面。首页承载“此刻 / 记录 / 生活”三个主标签；列表与详情页承载生活项目检索、筛选、状态、编辑和来源。没有为每张 Stitch 图单独建一个原生页面，相关设计被映射为这些页面中的状态、行项目或操作面板。

代码中的真实接口包括 `/v1/captures`、`/v1/life`、`/v1/now`、`/v1/locations`、`/v1/media`、`/v1/settings`、`/v1/ui-capabilities` 和 `/v1/records/export`。API/客户端代码存在不等于已在生产或用户真机完成验收；文档不声称本轮完成部署验证或真机视觉验收。

## 样式、操作和验证边界

新增原生页面沿用全局字体，没有本地 `font-family` 覆盖或斜体；页面正文和状态文字使用至少 `28rpx`。主要设置行与问卷选择卡约 44px 或更大的点击高度；返回、跳过等紧凑工具按钮更小。设置页采用焦糖纸面配色和清晰行项目，设置选项在底部面板展开；首次问卷继续使用大选择卡。页面样式约束已从源码核查，未据此声称在真机上视觉验收通过。

契约构建与小程序类型检查通过；下节分别记录完整回归和原生开发者工具证据。微信分享选择器、真实位置权限和真机视觉效果不能由类型检查替代。

## 本轮验证与原生预览

- 首轮 UI 实现验证：构建、格式与差异检查通过，26 个单元测试文件共 556 项、13 个集成测试文件共 179 项通过。功能适配补充后的最终结果见本文最后一节。
- 20 份最终 HTML 均可读；10 张缺失或损坏的页面 PNG 已由真实 Chromium 重建，外部图片和所用字体加载完成。
- 空闲页氛围图来自最终第二包第 4 页的资源，作为装饰使用；未将稿件中的星期、天气、温度、茶品或室内状态写成用户事实。
- 微信开发者工具已导入独立原生验收包，实际渲染欢迎页和设置页；修复 WXSS 通配选择器不兼容、v2 默认按钮固定 184px 两个原生布局问题。所有页面统一用 WebView 渲染原生 WXML。
- Page 运行状态在 onLoad 创建，避免非简单对象深拷贝；初次列表请求中隐藏后可恢复；清图片缓存同时作废首页内存路径及迟到文件写入。
- 本地验收 API 仅监听 127.0.0.1:3017，使用随机私有 PostgreSQL schema、独立测试账号和标注“验收测试”的数据，不调用外部模型或地图服务，不触碰 staging 数据。
- 用户明确授权后，仅在独立 `kairos-stitch-ui` 验收项目开启开发者工具的“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”组合选项；正式项目配置仍保留校验。原生开发登录、三步问卷、条件面板、生活分组、文字搜索、详情标题修改、来源原文/图片、喜欢评分、状态更新、设置保存/回读、图片缓存清理、文字记录提交和 Now 建议生成已通过本地 UI 操作及实际 API 回执验证。仅使用标注验收测试的数据。
- 微信右上角胶囊由运行环境提供，未在 WXML/WXSS 中复制；五个页面均只读取 `wx.getMenuButtonBoundingClientRect()` 为其预留空间。
- 原生检查发现生活卡片英文内部枚举、分组重复标题、搜索模式标题不准确及类型限定的推荐文案，均已修正；来源正文改用 `user-select` 避免弃用提示。
- 导出 GET 返回 200，但模拟器中的文件分享环节失败；界面明确告知需在手机微信中完成分享。未执行向联系人发送文件，真机分享仍待验收。
- 本次原生修正后的默认构建、格式检查、差异检查及 88 项相关页面/缓存回归通过；独立预览已刷新并回读中文卡片和正确导出提示。原生回读导出数量为 5 条，重新进入设置仍显示保存后的半小时偏好。
- 首页搜索采用 ALL_RECORDED 范围，覆盖当前账号的 ACTIVE 与 RESOLVED 记录；分组浏览仍采用 SECTION 原有语义。归档与删除不包含在全局搜索结果内，游标绑定账号、范围及筛选条件。
- 真机尺寸/字体、语音性能、真实地图路线、文件分享、生产部署均未完成本轮验收。

## 功能适配补充检查

- 记录列表使用固定创建截止时间与微秒级排序游标，每页 50 条；仅图片预取有 12 张预算，记录展示不再被截断。103 条记录的接口回归覆盖 50/50/3 分页、并列时间、账号隔离、删除过滤和后插入记录。
- 原生图片选择器与地图选择器跨 onHide/onShow 保留当前操作；账号切换及卸载会作废迟到返回。保存与反馈失败重试复用幂等键，防止重复提交或旧响应覆盖新操作。
- 详情选点经后端签名意图、对象版本与所有权复核，用户确认后保存。selectedDestination 与 EXTERNAL_VERIFIED 的 verifiedDestination 分开，用户选点不代表营业、商户身份或路线已经核实。
- 手动结束、归档或删除项目会关闭对应未完成的建议与会话，清除本机路线缓存。历史“跳过后又开始”的活动也按事件顺序正确取消；不把取消伪装成完成或不喜欢。
- 路线及附近位置只由主动操作触发；关闭定位偏好时额外确认，不自动修改长期偏好。页面返回与筛选翻页不反复请求 GPS。
- 登录刷新失败后的账号清空会重置页面数据和操作状态，防止旧账号内容残留及永久加载。

外部模型整理、腾讯地图真实路线、手机语音与文件分享仍需对应服务配置及真机验证；推送、任意 POI 探索和票券核验保留明确接口与未接入反馈，不以占位页面冒充可用能力。
