## 首次使用

微信登录建立独立账户。首次进入和恢复登录都会查询服务器的引导完成状态，未完成时进入四步引导。读取失败提供重试，也可以继续记录；不会将失败当成已完成。

| 步骤 | 用户填写或选择                                                          | 保存与作用                                                                     |
| ---- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 1    | 昵称，可选，最多 32 字符                                                | 个人资料，仅用于账户展示；不自动获取微信昵称                                   |
| 2    | 安静、探索、社交或不设偏好                                              | 推荐情境的放松倾向                                                             |
| 3    | 通常可用的 15/30/60/120 分钟；50/100 元以内或不设预算                   | 推荐的默认时间与预算；预算换算成分；当次条件可以覆盖                           |
| 4    | 愿意出门、在家或每次决定；可选城市/片区；是否允许主动核对路线时使用位置 | 出门意愿参与推荐；区域仅为文字偏好；开启位置选项不会自动调用定位或取得微信授权 |

头像和简介可以在“设置 → 个人资料”补充，均可不填。支持清空昵称、移除头像；头像经压缩与校验后保存，不接收远程头像 URL 或客户端提供的账户身份。没有姓名、手机号、性别、生日、详细住址等必填项。

“保存并开始使用”先保存填写的昵称，再保存问卷并标记完成。任一请求失败留在原页面；丢失响应的重试复用幂等键，已确认保存的昵称不重复提交。“暂时跳过”只保存完成状态，不保存表单草稿、不改原有偏好；重新登录后不再反复弹出。可以在设置中重新填写。

## 使用界面

新账户没有预置记录、地点、票券、推荐或样例数据。首页空态引导留下第一条记录，然后使用既有文本、图片、语音保存与解析流程；数据始终按服务器验证的微信账户隔离。

已移除录入页的“预约日期/关联票券待接入”占位内容，隐藏不可用的票券核验与提醒操作、未接入的推送开关；外观页仅显示已实现的主题。相应后端接口继续返回明确的能力状态。隐私入口打开小程序在微信配置的保护指引。

自动化测试和本地演示工具属于开发验证资源，不进入原生用户页面。没有将用户已有的普通生活记录按关键词猜测为测试数据并删除。线上只读核对有 5 个微信身份、29 条普通记录，未发现 `local-demo:%` 开发身份；部署前后普通账户和记录数量一致。本轮没有按关键词删除线上记录。

## 后端和发布包

新增 `0003_user_profile.sql` 为用户表添加资料字段及头像约束，不重写已执行的迁移。同期隐私清理使用 `0004_privacy_retention.sql`，新增最后使用时间和清理索引。最终部署应基于合并后的完整 main 提交，同步迁移、API、Worker 和原生客户端；早期九文件增量包只涵盖个人资料准备，不能作为完整合并版本的部署包。部署时核对现有版本与源码哈希，先保存并验证私有数据库备份，再运行未执行的迁移和切换服务；不重建数据库、不修改域名或密钥。

生产配置强制真实 AppID、微信登录和公网 HTTPS。`pnpm build:miniprogram:release` 对开发/测试环境配置直接报错。生产服务禁止 `MODEL_PROVIDER=mock`；部署模板默认 Qwen，部署脚本要求真实模型配置。不存在故障时自动切换模拟模型的路径。

客户端为 `0.3.0`，使用现有 AppID 和 HTTPS 后端地址，产物在 `apps/miniprogram/dist`。公开生产客户端配置保存于 `apps/miniprogram/config.production.json`，仅含公开的 AppID、地址和版本，不含密钥。可重复构建：

```sh
MINIPROGRAM_CONFIG="$(pwd)/apps/miniprogram/config.production.json" pnpm build:miniprogram:release
```

服务器完整增量包、哈希、部署脚本、本地回执摘要和原生页面截图保存在 `.local/new-user-release/`，不提交 Git；服务端密钥始终保留在服务器。
