# 原生微信小程序接入计划

2026-10-04。基于 main `9bf2b0a` 和[生活决策小程序产品与开发说明](https://chatgpt.com/space/page_4d6dfd5f7714819182fb830d7a1c7472)。用户确认尚无 AppID 和云环境，先完成代码与配置，再做真实服务联调。此轮将现有后端供原生微信客户端使用，保留 API、Worker、PostgreSQL 架构。

## 交付目标

提供可构建、可导入微信开发者工具的 TypeScript / WXML / WXSS 客户端，跑通登录 → 文本回执 → 后台理解 → 生活列表 → 情境决策 → 接受或更换。真实微信模式使用 wx.login 与服务端 code2Session；无凭证的开发模式须显式选择，不自动回退。现有网页 Demo 保留。

## 当前基础与缺口

已有认证、会话轮换、文本管线、Outbox Worker、推荐、反馈、共享 Zod 契约和 PostgreSQL 集成测试。现有微信调用缺少完整异常分类与配置预检；没有小程序工程、客户端会话管理、弱网重试策略或环境构建门禁。现有列表有数量上限，完整产品的媒体、追问、偏好重建、账号清理和生产运维仍未实现。

## 页面方向

遵循产品说明：默认此刻、中央输入、生活入口；首页不放品牌标题、统计仪表盘或常驻输入框。单个建议占据主体，输入面板提交成功即显示“收到了”。生活页呈现当前后端确实支持的最近记录及处理状态，不编造完整六组智能分类。

配色为雾白 #F5F7F6、墨绿 #233C35、叶灰 #72827B、浅苔 #DEE7DF、纸白 #FFFFFF。正文用系统无衬线，单一行动标题用系统宋体候选；不下载外部字体。采用留白与低饱和悬浮底栏，中央圆形输入按钮为识别点；先验证原生组件兼容性，复杂 Liquid Glass 和 Worklet 转场在真机阶段深化。

```text
此刻                         生活
当前条件                     最近留下
                             文本对象与摘要
一个主要行动                 原始输入与处理状态
依据与下一步
接受 / 换一个
       [此刻  +  生活]               [此刻  +  生活]
```

## 环境与身份约束

AppID 可进入公开构建配置；AppSecret、JWT 密钥和数据库连接只在服务端。环境之间不得共享数据库、微信身份配置或会话缓存。一个部署绑定一个小程序 AppID，切换 AppID 不复用旧身份库。客户端不得将 OpenID 当 user_id，不保存微信 session_key，不请求手机号；录音、位置及图片选择按用户主动输入或筛选操作触发。

登录 code 单次使用，不盲目重试 code2Session。刷新响应丢失时重新登录；现有服务端刷新轮换未提供可重放响应，因此客户端不重复提交同一个 Refresh Token。业务写请求仅在同一个逻辑操作内复用 UUID；用户修改内容后创建新键。
